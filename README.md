# 퍼팅 챌린지 (시험용 안드로이드 앱 · 0.6)

3D 골프 퍼팅 게임 시험판입니다. 100단계 모두 열려 있고, 인터넷 없이도 실행됩니다.

## 설치 파일 받기
휴대폰에서 아래 링크를 누르면 바로 받아집니다. (약 230KB)

**https://github.com/hwani172/putting-challenge-app/raw/main/putting-challenge.apk**

## 설치 순서 (삼성 휴대폰 기준)
1. 위 링크를 눌러 `putting-challenge.apk`를 받습니다.
2. 받은 파일을 누릅니다. (알림창 또는 **내 파일 → 다운로드**)
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 돌아와 **설치**를 누릅니다.
4. Play 프로텍트 경고가 나오면 **세부정보 → 무시하고 설치**를 누릅니다.

안드로이드 7.0 이상에서 설치됩니다.
